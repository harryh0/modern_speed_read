# Modern Speed Reader

A lightweight browser app for practicing focused, faster reading.

**Live app:** https://harryh0.github.io/modern_speed_read/

## How to use it

1. Paste up to 1,000 characters into the text box.
2. Adjust the reading-speed slider. The number beside the slider is the current words-per-minute rate.
3. Choose a **Chunk size** after adding text. A chunk can contain anywhere from one word to the full passage.
4. Select the square play button above the reader to start. Select it again to pause or resume.
5. You can also use **Space** or **Enter** to play and pause when you are not typing in an input.

The reader displays one chunk at a time. In the source text, yellow highlights the active chunk and light blue tracks the individual word currently being read.

Use the chevron beside the title to collapse or reveal the text and speed controls.
